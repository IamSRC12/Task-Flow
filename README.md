## ✨ Features

- ✅ Create, organize & prioritize tasks
- 🔄 Workflow stages & status tracking
- 💾 Local persistence — no cloud required
- 🖥️ Desktop-native (Electron) + quick launch via `START.bat`

## 🚀 Quick Start

```bash
npm install
npm run dev      # dev mode
# or
START.bat        # Windows one-click launch
```
